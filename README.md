# Last Out — Survivor 51

Fantasy game for CBS *Survivor* 51 after the first torch is snuffed.

**Aaliyah Puglia** (Toka, chef, 24) was voted out 6–2 over Jenna Doore on Day 3 of Episode 1, “Permanent Uncertainty.” Twenty castaways remain. Last Out is a game about who gets knocked out last.

## What it is

- Draft / own remaining Season 51 players
- Score points for surviving, finding idols, winning advantages and immunities
- Head-to-head matchups like fantasy football
- Season table is a round-robin like the Premier League (3 pts win, 1 draw)
- Trade picks with other managers
- League chat
- Email/password login stored on-device so the same Expo app runs on **iOS and Android** (and web)

## Scoring

| Event | Points |
| --- | --- |
| Survive an episode | 8 |
| Hidden immunity idol found | 15 |
| Idol played correctly | 12 |
| Advantage found / won | 10 |
| Individual immunity | 12 |
| Tribe immunity | 3 |
| Reward win | 4 |
| Vote received | -2 |
| Shot in the Dark played | 1 |
| Last player standing | 50 |
| Sole Survivor | 40 |

Week 1 already applied: Rob Antonson +15 for the Savu tree idol; Savu +3 tribe immunity; Jenna −4 for two votes +1 SitD.

## Run on a phone

```bash
npm install
npx expo start
```

- iPhone: scan the QR code with the Camera app (Expo Go)
- Android: scan with Expo Go
